Full-Duplex-Bench-JA Leaderboard

日本語のフルデュプレックス音声対話モデルが、相手の話の途中のポーズにどう反応するか(Pause Handling)と、 相手のターンの終わりで話し始められるか(Smooth Turn-Taking)を、実際の人間どうしの対話(LLM-jp-Zoom1)で採点しました。 順位は課題ごとに付けます。Pause はポーズに反応しなかった割合と、相手に被せて話し続けた割合の和(小さいほど良い)、 Smooth TT は話し終わりでターンを取った割合(TOR、大きいほど良い)です。 Pause の TOR(ポーズでターンを取った割合)は、聴取実験で人の判断と逆を向いたため、順位には使わず参考値として残しています。

範囲: Full-Duplex-Bench v1 の 4 課題(Pause Handling / Backchanneling / Smooth Turn-Taking / User Interruption)のうち、相手(話者 A)の音声を固定して測れる 2 課題(Pause Handling、Smooth Turn-Taking)を日本語の実対話で実装しています。 Backchanneling(システムの相槌)は事象の定義だけを公開しており、採点していません。User Interruption(ユーザの割り込み)と、v1.5 が扱う重なりの場面(ユーザの相槌、第三者・背景の発話)には未対応です。

順位の一覧

順位は課題ごとに付けます。2 課題は指標の向きも尺度も違うため、まとめた総合の順位は付けていません。 並びは Pause の順位です。自明なベースライン(常時沈黙、常時発話)は順位の対象外です。

in-domain = 評価データと同じ LLM-jp-Zoom1 を学習に含む(参考値)

人の順位との順位相関(Pause)

指標の位置づけ: ターンテイキングの指標は「人が自然と感じる範囲(許容範囲)の外に出ているか」を測るもので、許容範囲の中の個性(相槌の多寡、間の長短)は採点しません。 Smooth TT では「録音の人間 B に近い」が許容範囲の中心として成り立ちましたが、Pause では成り立たなかったため、Pause の順位は「ポーズで短く反応したか(相槌の有無)と、相手に被せて続けなかったか」を数える指標で付けています。 相手の発話中の相槌(Backchanneling)は別の課題として定義のみ公開しています(未採点)。

注意

    サンプル音声

    各課題の例クリップ(20 秒、LLM-jp-Zoom1 からの抜粋)。波形をタップで再生/停止。 青い帯が評価の窓、橙の縦線が人間 B の応答・相槌の開始点。相槌の例は定義を示すためのもので、採点の対象外です。

    境界

    話者 A と人間 B の発話の境界を、音声から置くか、ASR の文字の時刻から置くかを切り替えます。 青い帯・橙の縦線・TO / D のバッジが、選んだ定義の値に変わります。

    バッジの見方

    TO バッジは Full-Duplex-Bench と同じく、モデルの応答の転写(ASR)の時刻から判定します。転写に乗らない発声や整列誤差は 拾えないため、まれに波形の見た目と食い違うことがあります。VAP-distance (D) は生波形から計算されるため、この影響を受けません。 「無出力」バッジは、そのモデルが全区間で音声を返さなかったことを示します(沈黙が正解の課題では、正しく黙ったのか 何も生成できなかったのかを指標だけでは区別できません)。

      注記

      指標の定義

      TOR = モデルがターンを取った割合(Full-Duplex-Bench と同じ二値の判定)。Smooth TT の順位は TOR(話し終わりでターンを取った割合 = 望ましい振る舞いの割合)で付けます。 無反応 + 割り込み(Pause の順位)= ポーズごとに、無反応(ポーズの中に 0.2 秒以上の声が無い)と 割り込み(ポーズの中で話し始めて相手の再開後も 0.5 秒以上続ける、またはポーズの前 2 秒で相手と 0.5 秒を超えて重なる)をそれぞれ 0 / 1 で数え、和を事象で平均した値 (0〜2、小さいほど良い。応答音声のエネルギーから判定し、転写は使いません。相槌・息・雑音は区別しません)。何も出力しないと 1.0 になります。 Pause の TOR は Full-Duplex-Bench の定義(ポーズでターンを取らないほど良い)の値で、聴取実験で人の判断と逆を向いたため参考値です。 2 課題は指標の向きも尺度も違うため、まとめた総合の順位は付けていません。 VAP-distance(実験的)= 人間の音声活動予測(VAP)分布とモデル応答の分布の距離(DKL、小さいほど人間の応答に近い)。 相槌は事象の定義のみを公開しており、採点の対象外です。

      境界と転写

      人間側の発話境界は音声の境界(人間側 A・B の境界を音声の VAD で付け直したもの、ツールキットでは detection.boundaries: audio)。ツールキットの既定(transcript)は文字の境界です。 モデル応答の転写は ASJ の講演論文(README「引用」)と同じ手順(ReazonSpeech-ESPnet で書き起こし、WhisperX で文字の時刻を整列)。 ツールキット既定の ASR で一から回すと TOR は一致しません(文字の終端が後ろの無音まで伸びるため)。
