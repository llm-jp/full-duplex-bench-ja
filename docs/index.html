Full-Duplex-Bench-JA Leaderboard

日本語のフルデュプレックス音声対話モデルが、相手の話の間で黙っていられるか(Pause Handling)と、 相手のターンの終わりで話し始められるか(Smooth Turn-Taking)を、実際の人間どうしの対話(LLM-jp-Zoom1)で採点しました。 順位は望ましい振る舞いの割合(Pause は間でターンを取らなかった割合 = 1 − TOR、Smooth TT は話し終わりでターンを取った割合 = TOR)です。 ただし Pause のこの値は「黙るほど高い」定義で、人の判断とは逆を向くことが分かっています。

範囲: Full-Duplex-Bench v1 の 4 課題のうち、相手(話者 A)の音声を固定して測れる 2 課題(Pause Handling、Smooth Turn-Taking)を日本語の実対話で実装しています。 システムが先に話している場面(ユーザの相槌、ユーザの割り込み)と、第三者・背景の発話には未対応です。

人の順位との順位相関(Pause)

指標の位置づけ: ターンテイキングの指標は「人が自然と感じる範囲(帯)の外に出ているか」を測るもので、帯の中の個性(相槌の多寡、間の長短)は採点しません。 Smooth TT では「録音の人間 B に近い」が帯の中心として成り立ちましたが、Pause では成り立たず、検証中の Pause 指標は「間で短く反応したか(相槌の有無)と、相手に被せて続けなかったか」を測ります。 相手の発話中の相槌(Backchanneling)は別の課題として定義のみ公開しています(未採点)。

注意

    サンプル音声

    各課題の例クリップ(20 秒、LLM-jp-Zoom1 からの抜粋)。波形をタップで再生/停止。 青い帯が評価の窓、橙の縦線が人間 B の応答・相槌の開始点。相槌の例は定義を示すためのもので、採点の対象外です。

    バッジの読み方

    TO バッジは本家 Full-Duplex-Bench 準拠の転写ベースの判定です。転写に乗らない発声や整列誤差は 拾えないため、まれに波形の見た目と食い違うことがあります。VAP-distance (D) は生波形から計算されるため、この影響を受けません。 「無出力」バッジは、そのモデルが全区間で音声を返さなかったことを示します(沈黙が正解の課題では、正しく黙ったのか 何も生成できなかったのかを指標だけでは区別できません)。

      注記

      指標の定義

      TOR = モデルがターンを取った割合。望ましい振る舞いの割合 = 課題で望ましいとされる側(Pause はターンを取らない、Smooth TT は取る)に一致した割合 (Pause は 1 − TOR、Smooth TT は TOR。本家 Full-Duplex-Bench と同じ二値の判定)。総合 = 2 課題の平均。 VAP-distance(実験的)= 人間の音声活動予測(VAP)分布とモデル応答の分布の距離(DKL、小さいほど人間の応答に近い)。 相槌は事象の定義のみを公開しており、採点の対象外です。

      境界と転写

      人間側の発話境界は音声の境界(人間側 A・B の境界を音声の VAD で付け直したもの、ツールキットでは detection.boundaries: audio)。ツールキットの既定(transcript)は文字の境界です。 モデル応答の転写は論文と同じ手順(ReazonSpeech-ESPnet で書き起こし、WhisperX で文字の時刻を整列)。 ツールキット既定の ASR で一から回すと TOR は一致しません(文字の終端が後ろの無音まで伸びるため)。
