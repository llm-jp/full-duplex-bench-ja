Full-Duplex-Bench-JA Leaderboard

日本語フルデュプレックス音声対話モデルの ターンテイキング能力(ポーズ処理・話者交代)の評価結果。

総合ランキング

総合 = 各タスクの平均。適合率↑(本家 Full-Duplex-Bench と同じ 二値 TOR で、相手の振る舞いに一致した割合)で順位付け。 VAP-distance↓(人間の音声活動予測分布との距離)と スコア↑(exp(-α·DKL))は実験的指標で、 人手判断との相関などの検証が済むまで参考値として併記します。

タスク別

サンプル音声

各タスクの例クリップ(20秒)。刺激音声(話者A)に対する 人間Bの実応答(正解)と各モデルの応答の波形。波形クリックで再生/停止。 ハイライト帯が評価対象のイベント窓、橙の縦線が人間Bの応答/相槌の開始点。 モデル行は VAP-distance(D)昇順。音声は LLM-jp-Zoom1 からの抜粋。 「無出力」バッジは、そのモデルが全区間で音声を返さなかったことを示します (ポーズ処理のように沈黙が正解のタスクでは、正しく黙ったのか何も生成 できなかったのかを指標だけでは区別できない点に注意)。

※ TO バッジは本家 Full-Duplex-Bench 準拠の ASR 転写ベースの判定です。転写に乗らない発声や整列誤差は 拾えないため、まれに波形の見た目と食い違うことがあります。 VAP-distance (D) は生波形から計算されるため、この影響を受けません。

評価予定モデル

アダプタ整備・実走待ち。整い次第このリーダーボードに追加します。

    指標の定義: TOR = モデルがターンを取った割合。 適合率 = 相手(人間B)の実際の振る舞いに一致した割合。 VAP-distance(実験的) = 人間の音声活動予測(VAP)分布とモデル応答の 分布の距離(DKL, 小さいほど人間の応答に近い)。検証中のため参考値。
