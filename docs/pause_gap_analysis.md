# Pause gap-stratified analysis

既存の Pause 200クリップを、モデル API を再実行せずに再分析した。検出された
240事象をターン内ギャップ長で層別化した。95%信頼区間はクリップを単位とする
10,000回のbootstrapにより求めた。

各層の事象数は、0.4--0.6秒が78、0.6--0.8秒が115、0.8--1.0秒が47で
あった。この不均衡は既存の無作為抽出に由来し、次版で層別抽出が必要である。

| Model | 0.4--0.6 s TOR | 0.6--0.8 s TOR | 0.8--1.0 s TOR | Long-short difference (95% CI) |
|---|---:|---:|---:|---:|
| J-Moshi | .397 | .348 | .383 | -.014 [-.195, .163] |
| J-Moshi-ext | .179 | .217 | .404 | .225 [.058, .395] |
| LLM-jp-Moshi-v1 | .372 | .461 | .468 | .096 [-.090, .278] |
| Gemini Live | .218 | .339 | .340 | .122 [-.035, .287] |
| GPT Realtime | .192 | .183 | .298 | .106 [-.047, .260] |
| Grok Voice | .103 | .400 | .447 | .344 [.190, .498] |

Pauseでは沈黙維持が望ましいため、TORは低いほどよい。Grok Voiceと
J-Moshi-extでは、長いポーズに対する誤Takeoverの増加について95%区間が0を
跨がなかった。Gemini Live、GPT Realtime、LLM-jp-Moshi-v1も点推定値は正だが
区間は0を跨いだ。J-Moshiではポーズ長に伴う悪化は確認されなかった。

本結果は不均衡な既存標本を用いた事後的層別分析であり、新たに構築した均衡
ベンチマークではない。次版では各層から同数を抽出し、全体値には各層の
unweighted macro averageを用いる。
